## 재현 명령

저장소 루트에서 실행한다. `requirements.txt`에는 추가 패키지가 없다.

```powershell

python examples/offline_demo.py
```

첫 명령은 검사 수와 통신 차단 상태를 JSON으로 출력한다. 두 번째 명령은 SAY 한 행동과 불확실한 답변의 음성 표식 차단을 고정 입력으로 보여 주며 내부 assertion으로 결과를 확인한다. README의 예시 출력과 비교할 수 있다.

활성 코드·검사·예시의 Python 구문도 검사했다. 보존 팀원 원본 7파일과 현재 활성 코드 7파일은 기존 `assets/development_baseline.json`의 SHA-256과 일치하는지 확인했다. 게시용 파일과 로컬 원본의 차이는 문서·메타데이터의 PC 식별 정보 제거 및 테스트 UUID 익명화로 한정한다.
